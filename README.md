# dokusho-import

読書メーターのユーザーIDから、ブクログのインポートCSVを作ります。

スクリーンショット＋OCRではなく、読書メーターの本ページに貼られている
Amazonリンクから**ISBNを一次情報として直接**取ります。

## 仕組み

読書メーターの `book_id` は「版」単位です（紙とKindleは別ID）。
そのため `user_id → book_id` のリストが完全に取れれば、**版の取り違えは
原理的に起きません**。「複数の版があれば最新」というルールが必要になるのは、
ISBNが取れずタイトルから逆引きする場合だけです。

1. `https://bookmeter.com/users/<id>/books/read?page=N` を1ページずつ取り、
   `book_id` と読了日を集める
2. 各 `https://bookmeter.com/books/<book_id>` から
   `amazon.co.jp/dp/<10文字>` を抜き、**チェックディジットを検証**して
   ISBN-10 か ASIN かを判定。ISBN-10 は ISBN-13 に変換する
3. `--ndl-fallback` を付けた場合のみ、ISBNが取れなかった本を
   国立国会図書館サーチで逆引きし、**出版日が最新の版**を採る
4. ブクログCSVと、未解決分のCSVを書き出す

いずれも**ログイン不要・JavaScript不要**なので、標準ライブラリだけで動きます
（追加インストールなし、Python 3.11 以降）。

## 使い方

```bash
# 実際に読書メーターから取得する
python3 -m dokusho_import.cli --user-id 123456 --out booklog.csv

# まず数冊だけで試す
python3 -m dokusho_import.cli --user-id 123456 --limit 3 --out /tmp/try.csv

# 冊数をプロフィール表示と照合する（合わなければ終了コード2）
python3 -m dokusho_import.cli --user-id 123456 --expect 140 --out booklog.csv

# ネットワークに出ず、保存済みHTMLだけで動かす
python3 -m dokusho_import.cli --html-dir ./fixtures --out booklog.csv
```

主なオプション:

| オプション | 既定 | 用途 |
|---|---|---|
| `--interval` | `2.0` | リクエスト間隔（秒）。直列＋ゆらぎ付き |
| `--cache` | `.cache/bookmeter.json` | 本ページのキャッシュ。再実行で再取得しない |
| `--expect N` | なし | 冊数照合。取りこぼしを検知する |
| `--status` | `読み終わった` | 読書状況カラムの値 |
| `--encoding` | `utf-8` | `utf-8-sig` / `cp932` も指定可 |
| `--header` | なし | ヘッダ行を付ける |
| `--quote-all` | なし | 全カラムを引用符で囲む |
| `--ndl-fallback` | なし | 未解決分をNDLで逆引き（最新版を採用） |

## 出力するCSVの列

公式ヘルプ（「他の読書管理サイトからブクログへデータを移行したい」
「インポート機能」「サービスIDとアイテムIDとは何ですか」）の記載に基づく11列:

```
サービスID, アイテムID, 13桁ISBN, カテゴリ, 評価, 読書状況,
レビュー, タグ, 非公開メモ, 登録日時, 読了日
```

| 列 | このツールが入れる値 |
|---|---|
| サービスID | Amazonコードがあれば `1`（Amazon.co.jp）、なければ空 |
| アイテムID | ISBN-10（Amazonリンク由来）。なければ空 |
| 13桁ISBN | ISBN-13。**アイテムIDとどちらか必須** |
| カテゴリ | 空 |
| 評価 | 空（読書メーターに相当項目がない） |
| 読書状況 | `読み終わった`（`--status` で変更） |
| レビュー | 空 |
| タグ | 空（`--tags` で付与） |
| 非公開メモ | 出典の読書メーターURL（後から追跡できるように） |
| 登録日時 | `yyyy-mm-dd hh:mm:ss`。読了日の 00:00:00 |
| 読了日 | `yyyy-mm-dd` |

`登録日時` は `yyyy-mm-dd hh:mm:ss` でないと全件がインポート日時に
上書きされるため、19文字であることを検証しています。

### スペース・カンマの扱い

タイトル・著者・レビューにはカンマ、半角/全角スペース、改行が入りえます。

- 入力側: HTMLエンティティを戻し、全角スペース・NBSP・改行を半角スペース1個に
  畳んで前後を落とす（`textnorm.clean`）
- 出力側: カンマ・引用符・改行を含む場合に加えて、**前後に空白が残っている
  場合も引用符で囲む**。ブクログ側のパーサが引用なしフィールドの前後空白を
  削っても値が変わらないようにするため（`booklog.quote_field`）
- 検索キーとして使うときだけ空白を完全除去し `NFKC` 正規化する
  （`夏目 漱石` と `夏目　漱石` を同一視、`textnorm.collapse_for_match`）

## 確実性の担保

推測でISBNを埋めないことを優先しています。

- **チェックディジット検証**: Amazonリンクの10文字は必ず ISBN-10 の検証を
  通す。通らなければ ISBN として扱わない（`B0...` の Kindle ASIN は除外）
- **冊数照合**: プロフィールの「読んだ本 N冊」と取得件数を突き合わせる。
  合わなければ終了コード `2`。ページングの取りこぼしを黙って通さない
- **ISBN-13 の再検証**: 書き出す全行のチェックディジットを確認
- **重複検出**: 複数の `book_id` が同じISBNに解決したら警告（取得ミスの兆候）
- **未解決は別CSVに出す**: ISBNが取れなかった本は、URL・タイトル・著者・
  理由付きで `unresolved.csv` に出す。空欄のまま本CSVに混ぜない

## 読書メーターへの負荷

- 直列・既定2秒間隔（ゆらぎ付き）。140冊なら実時間5分弱
- 本ページはキャッシュするので、再実行時に同じページを取り直さない
- `--user-agent` に自分の連絡先を入れてください（既定値はプレースホルダ）
- 実行前に `https://bookmeter.com/robots.txt` を確認してください

## テスト

```bash
python3 -m unittest discover -s tests -t .
```

`tests/fixtures/` のHTMLは**合成データ**です（詳細は
`tests/fixtures/README.md`）。クラス名に依存しないパーサであることを
検証するもので、実物のHTML構造に対する検証は別途必要です。
